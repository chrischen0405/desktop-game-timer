# Desktop Game Timer

一个简洁实用的多人游戏计时器，支持多人轮流计时、暂停、重置等功能。

## 功能特性

- **多人计时**：支持 1-8 位玩家同时参与游戏计时
- **轮流计时**：点击当前计时的玩家自动切换到下一位玩家
- **单次计时**：显示每位玩家的总用时和当前轮次的用时
- **暂停功能**：中间暂停按钮可暂停所有玩家计时
- **重置确认**：重置操作需要二次确认，防止误操作
- **自定义配置**：可设置玩家数量和昵称
- **美观界面**：现代化毛玻璃设计，视觉体验优秀

## 技术栈

- Vue 3.3
- TypeScript 5.3
- Vite 4.5
- SCSS

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 使用说明

1. **开始计时**：点击任意玩家面板开始计时
2. **切换玩家**：点击当前计时的玩家，自动切换到下一位
3. **暂停**：点击顶部"暂停"按钮暂停计时
4. **继续**：点击"继续"按钮恢复计时
5. **重置**：点击"重置"按钮，清空所有计时数据
6. **设置**：点击右上角设置按钮，可添加/删除玩家、修改昵称
